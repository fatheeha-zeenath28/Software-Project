# A/L ICT Digital Learning Platform

An integrated digital learning platform designed to support Sri Lankan G.C.E. Advanced Level ICT students and teachers through academic content management, video-based learning, learning resources, quizzes, examinations, performance tracking and AI-powered educational assistance.

## Project Overview

The A/L ICT Digital Learning Platform aims to provide a centralized environment where students can access ICT learning materials and teachers can manage academic content and assessments.

The platform consists of three main applications connected through a shared backend.

### Applications

| Application | Description |
|---|---|
| Student Mobile App | Allows students to access lessons, videos, resources, past papers, quizzes, examinations, results and AI learning assistance. |
| Teacher Mobile App | Allows teachers to manage lessons, learning materials, videos, quizzes, examinations and student performance. |
| Admin Web Portal | Allows administrators to manage subjects, courses, classes, teachers, academic content and platform activities. |
| Backend | Provides APIs, business logic, data management and communication between applications. |

## Main Features

- Subject Management
- Course Management
- Class Management
- Syllabus and Topic Management
- Lesson Management
- Teacher-Class Assignment

### 2. Learning & Resource Management
- Educational Video Management
- Video Playback and Progress Tracking
- Learning Notes and Resources
- Past Paper Library
- Learning Activity History

### 3. Quiz & Assessment Management
- Question Bank
- Quiz Creation and Configuration
- Online Quiz Attempts
- Automatic Marking
- Quiz Results and Analytics

### 4. Examination Management
- Examination Creation and Scheduling
- Student Examination Registration
- Online Examination Interface
- Automatic Answer Saving
- File-Based Answer Submission
- Teacher Marking and Feedback
- Examination Results

### 5. AI Learning Assistant & Performance Analytics
- AI-Powered ICT Question Answering
- Sinhala and English Support
- Large Language Model (LLM) Integration
- Retrieval-Augmented Generation (RAG)
- ICT Learning Knowledge Base
- AI Conversation History
- Student Performance Analytics
- Rankings, Points, Badges and Streaks

### 6. Authentication, Integration & Deployment
- Student and Teacher Registration
- Admin Authentication
- Login and Logout
- Role-Based Access Control
- Password Recovery
- User Profile Management
- Notifications
- System Integration and Testing
- Production Deployment

## Project Management – Agile Scrum

Development is organized into six sprints using Jira.

| Sprint | Name | Main Focus |
|---|---|---|
| Sprint 01 | Academic & Content Management | Subjects, courses, classes, syllabus and lessons |
| Sprint 02 | Learning & Resource Management | Videos, resources, past papers and learning history |
| Sprint 03 | Quiz & Assessment Management | Question bank, quizzes and results |
| Sprint 04 | Examination Management | Online examinations, submissions and marking |
| Sprint 05 | AI & Analytics | AI Learning Assistant, RAG, analytics and gamification |
| Sprint 06 | Authentication & Deployment | Authentication, integration, testing and deployment |
